## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/jameelahmadagenticai-wq/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Type check and build minified production bundle
npm run build

# Preview production build locally
npm run preview
```
